# Шаблон отчёта ИТМО

Оформление взято из отчёта `activecore/report/lab-3`: титульный лист, шрифты, поля, оглавление, подписи рисунков и таблиц, оформление листингов. Содержательная часть прежней работы удалена.

Редактируйте `main.tex`. В начале файла задаются тема (`\title`), автор (`\author`), группа (`\group`), преподаватель (`\supervisor`), дисциплина (`\discipline`) и номер работы (`\labnumber`). Автор и группа сохранены из исходного отчёта; остальные данные нужно заполнить. Необязательная команда `\reportdate{28}{октября}` задаёт дату, год по умолчанию текущий.

В документе оставлены пустые разделы с комментариями: цель, задание, ход работы и вывод. Их можно переименовать или заменить. Рисунки помещайте в `figures/`; класс уже настроен искать их в этой папке.

## Сборка

Нужен TeX Live с XeLaTeX и latexmk.

### В VS Code

Откройте корневую папку `promella_memes` целиком и файл `report/main.tex`. В проекте есть настройки `.vscode/settings.json` для расширения LaTeX Workshop: они запускают `latexmk` с параметрами из `report/latexmkrc`, поэтому используется XeLaTeX. PDF открывается во вкладке редактора и находится в `report/main.pdf`.

Для сборки выполните команду **LaTeX Workshop: Build LaTeX project** в палитре команд. Для просмотра — **LaTeX Workshop: View LaTeX PDF file**. При сохранении `.tex` сборка запускается автоматически.

### В терминале

Из корня проекта:

```powershell
cd report
latexmk main.tex
```

Готовый PDF появится рядом с `main.tex`, в `report/main.pdf`. Сборка выполняется внутри `build/`: там остаются логи, вспомогательные файлы и рабочая копия PDF. В `report/` копируется только итоговый PDF.

Для автоматической пересборки при сохранении:

```powershell
latexmk -pvc main.tex
```

## Файлы

- `main.tex` — данные титульного листа и текст отчёта.
- `itmo-report.cls` — оформление ИТМО; перенесено без изменений.
- `latexmkrc` — сборка XeLaTeX внутри `build/` и копирование готового PDF в `report/`.
- `figures/` — папка для будущих рисунков.

Сборочные файлы и PDF исключены из Git через корневой `.gitignore`.
