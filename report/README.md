## Сборка

Нужен TeX Live с XeLaTeX и latexmk. Из корня проекта:

```powershell
cd report
latexmk main.tex
```

Готовый PDF появится в `report/main.pdf`. Сборка выполняется внутри `build/`: там остаются логи и вспомогательные файлы. Для автоматической пересборки при сохранении:

```powershell
latexmk -pvc main.tex
```

В VS Code можно использовать команды **LaTeX Workshop: Build LaTeX project** и **LaTeX Workshop: View LaTeX PDF file**, открыв корень проекта и `report/main.tex`.

## Файлы

| Путь | Назначение |
| --- | --- |
| `main.tex` | Титульный лист, настройки листингов и подключение разделов. |
| `sections/` | Задача, описание системы, разбор модели и свойств, автоматизация, результаты и выводы. |
| `listings/` | Фрагменты исходного кода без комментариев и команды проверки. |
| `figures/*.mmd` | Исходники схем Mermaid. |
| `figures/*.svg`, `figures/*.png` | Отрисованные схемы; PNG используются в PDF. |
| `itmo-report.cls` | Оформление отчёта ИТМО. |
| `verification/` | Итог скрипта, лог свойства прогресса и сводная статистика. |
| `latexmkrc` | Сборка XeLaTeX и копирование итогового PDF. |
| `build/` | Вспомогательные файлы сборки и визуальной проверки; исключены из Git. |

Схемы уже отрисованы, поэтому для сборки PDF Mermaid не требуется. При изменении модели следует также обновить соответствующие фрагменты в `listings/` и результаты верификации в тексте отчёта.
